# Contributing

Спасибо за интерес к проекту. Особенно полезны:

- проверка регулярных выражений на ложноположительных и ложноотрицательных примерах;
- предложения новых синонимов с PMID-примерами;
- воспроизведение подсчётов на более свежем снимке PubMed;
- улучшения доступности и мобильного отображения страницы.

Перед pull request запустите:

```bash
python scripts/test_method_dictionary.py
python -m py_compile scripts/*.py
```

Для содержательного изменения словаря добавьте положительный и, если термин неоднозначен, отрицательный регрессионный пример. Не меняйте определения категорий только ради получения желаемого тренда.
